# Fidelity — how far this model sits from a real machine

One row per thing that differs. **A row that is written honestly is finished work.** Closing the
gap is a separate decision, taken on the row, never implied by it.

Columns: what it is / what a real machine does / what this model does / the distance / **on
purpose?** / **how sure the real-world figure is**.

`ON PURPOSE` is one of:

- **YES** — a deliberate cut, usually the design pillar's "unless it is heavy to compute" clause,
  or a game constant. Nothing is owed.
- **FIT** — the shape is real, the level is a number solved to make one preset land. Honest, but it
  is not a measurement of anything.
- **ERROR** — the model is wrong and nobody has said why. **Nothing new may be built on an ERROR
  row without saying so out loud in the reply.**
- **DRIFT** — nobody decided this. It fell out of something else and has been treated as a decision
  since. Not necessarily wrong; just never chosen. Do not write `YES` on a row unless a decision was
  actually taken.

`SURE` is confidence in the **real-world** side, not in ours: **high** = textbook or well known,
**medium** = from memory of published figures, **low** = not checked against anything.

Nothing here is frozen. A better measurement beats any row on sight — re-measure, rewrite the row,
say what moved. That is not a scope question and never needs permission.

**The "this model" column is a record, not a reference.** Testing is against real-world physics
only: the "real machine" column, conservation, analytic solutions, published data. A figure the
simulation once printed cannot pass or fail anything, because the code that printed it has had bugs.

## Plant size — the names are borrowed, and nobody picked the sizes

**No preset states a power.** A `PLANTPRE` row is plumbing and a lattice; `D.power = latRating()`,
so the megawatts are an OUTPUT of the drawn core. The one figure anyone chose is the stock PWR's
1198 MWt, which `PEAK_M = 1.283` was solved to land on. Every row below it is whatever its own
drawing happens to rate at, on a board and a mass budget sized for that anchor.

So these are not scaled-down real plants and were never decided to be. They are drawings that carry
a real machine's NAME to say what kind of thing it is.
